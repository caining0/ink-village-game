# 青蘅角色升级与验证

用户的首要目标是完整、好看的三维角色。静态参考图、程序化脸部和单元测试通过，都不能作为美术验收结论。

**本方案美术验收失败：用户已明确否决旧版拼接外观。下文保留历史实现记录，当前仅作为占位。后续采用完整统一角色；已完成渲染修正，并记录付费整模候选、来源和待取得的资产，见[最新记录](qingheng-render-and-full-model-review.md)。完整模型尚未替换。**

本次先将官方允许修改、再分发的 pixiv VRM 样例头部接入现有角色，取代手工眼睛与嘴唇；保留自有中式衣裙、金饰、直剑、骨骼与战斗动作。这是候选改编方案，不等于还原用户参考图，也不等于完整角色已达到最终美术标准。

执行项目：

- [x] 核对模型内嵌授权，保留作者、来源和完整许可。
- [x] 制作可复现的头部导出脚本，保留眼部与嘴部真实网格、UV 贴图和眨眼形变。
- [x] 头部随原骨骼运动，原占位脸隐藏；采用柔和光照与丝料材质。
- [x] 人物页提供同游戏模型的正面、侧面、背面、近景、行走和试剑。
- [x] 浏览器加载、资源、模型边界与动态验证。
- [x] 导出实际画面的正侧背视图供用户审阅，保存于 `docs/visual-review/qingheng-v1/`。
- [ ] 用户美术验收；重点检查全身一致性、头发、服装和动态，未确认前不标记完成。

验证记录：19项 Node 测试全部通过，修改的 ES modules 和启动脚本语法检查通过。Chrome headless 实测人物页加载、四个视角、行走、试剑与手机尺寸；实测游戏启动、移动输入、轻击、御风开关、暂停和恢复；两轮浏览器检查均无页面错误或失败资源。当前自动化环境无法直接读取图片视觉内容，因此没有做出“已看过并确认美观”的判断。完整通关、真实 GPU 性能与美术验收仍待完成。
